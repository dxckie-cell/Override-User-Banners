# How to install

Paste this link into the Install Plugin section of the Revenge client:

<https://dxckie-cell.github.io/Override-User-Banners/Override-User-Banners/>

Supports overriding the profile banner of multiple users. In the plugin settings, tap "+ Add user" and enter each user's ID and banner image URL. Changes apply immediately.

# Known Issues

- Untested against every Discord build: if a banner doesn't show up, check logcat for lines tagged `[custom-banners]` to see which patches were applied.
- Banners are not changed anywhere outside the profile views.
