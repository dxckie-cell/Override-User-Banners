# How to install

Paste this link into the Install Plugin section of the Revenge client:

<https://dxckie-cell.github.io/Override-User-Banners/Override-User-Banners/>

Supports overriding the profile banner of multiple users. In the plugin settings, tap "+ Add user" and enter each user's ID and banner image URL. Changes apply immediately.

The bottom of the settings screen has a short Status list showing which parts of Discord the plugin found and patched.

# Known Issues

- Only the profile screen has been checked. Banners in other places (for example the server member list) may not change.
- If the Status list says "profile screen banner: NOT FOUND", this Discord build names things differently and banners will not show on the profile screen.
